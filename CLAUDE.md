# MiniSpice

A circuit simulator in Python, built as a portfolio project by an engineering student heading into electrical engineering. The full roadmap is in PLAN.md. Build the phases in order without stopping for review between them; the owner reviews the finished project at the end.


## Code rules

- Python 3, numpy for math, matplotlib for plots, pytest for tests.
- Keep code simple and readable over clever. Comment the "why," not the "what."
- Every new feature gets tests, including at least one circuit solved by hand.
- Node 0 is always ground.
- Clear error messages that tell the user what's wrong with their circuit.
- Libraries named in a PLAN.md phase are fine to add when we reach that phase. Ask me before adding any others.
- The browser app (Part F) uses plain HTML, CSS, and JavaScript, with Pyodide running the Python engine.
